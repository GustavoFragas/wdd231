Website Project Proposal Submission
1. Project Subject The subject of my website is "The Citadel Codex," a comprehensive fan resource and character directory for the television series Rick and Morty.

2. Project Description This website will be a dynamic digital companion allowing fans to explore the show's complex multiverse. It will consist of three distinct, cohesive pages built with raw HTML, CSS, and vanilla JavaScript (no frameworks).

Page 1 (Home/index.html): A dynamic landing page introducing the site's purpose, featuring a "Random Dimension Character" spotlight (using JS), and a clear navigation menu.

Page 2 (The Multi-Database): This is the core page. It will dynamically generate a grid of at least 15 distinct characters/items fetched from the Rick and Morty API. For each item, I will display at least four distinct data properties (Image, Name, Status, and Species). Clicking an item will open a modal dialog (required functionality) to show additional details about that character (Origin, last seen location, etc.). This page will also implement Local Storage to allow users to "bookmark" or "favorite" characters, persisting client-side.

Page 3 (Galactic Registry): This page will feature an HTML form allowing users to submit new character theories, register as "Citadel Residents" (submitting name, dimension, favorite quote), or submit feedback. This meets the form requirement.

3. Project Reason and Purpose I chose this subject for both technical and personal reasons:

Technical Feasibility: This project's required JavaScript components (dynamic data fetching, dynamic content generation, localStorage, modals) are perfectly matched with the available Rick and Morty API. The API is free, open, and has a rich data structure that guarantees I can easily generate 15+ items with 4+ unique properties, fulfilling all the complex constraints of the final build.

Personal Motivation: I enjoy the show, which will keep me motivated throughout the intensive design and development phases in weeks 5 and 6. It allows me to create a "something that did not exist before" that I find enjoyable.

Skill Application: Developing this site without TailwindCSS or Bootstrap forces me to master responsive design (from 320px mobile up to desktop) using standard CSS grid/flexbox and semantic HTML, directly supporting the learning outcomes.
