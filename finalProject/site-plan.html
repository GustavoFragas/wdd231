Site Plan

The Citadel Codex — WDD231 Final Project

Site Name

The Citadel Codex

The name references The Citadel of Ricks, the central multiverse hub from the show. "Codex" frames the site as a galactic database or encyclopedia — an authoritative record of the Rick and Morty universe, keeping the tone both thematic and descriptive.

Site Purpose

The Citadel Codex is an interactive encyclopedia that consumes the official Rick and Morty REST API (rickandmortyapi.com). It lets fans explore characters, episodes and locations across the multiverse.

  • Dynamic character grid fetched from the API, displaying image, name, status and species.
  • Modal dialogs for detailed character info (origin, last known location, episode count).
  • Favorites system using localStorage so bookmarks persist between sessions.
  • Galactic Registry form where users can register as Citadel Residents and submit theories.

Scenarios

Scenario 1

"I want to quickly find out whether Rick C-137 is alive, dead, or unknown in the database. Where do I look?"

The user navigates to The Multi-Database page, types "Rick" in the search field and filters by species "Human." The character card for Rick Sanchez C-137 displays his status badge immediately. Clicking the card opens a modal with full details including origin dimension and last known location.

Scenario 2

"I found three characters I love. How do I save them so I can come back to them later without searching again?"

Each character card has a bookmark icon. Clicking it saves the character ID to localStorage. A dedicated "Favorites" filter on the same page shows only bookmarked characters. The bookmarks persist when the browser is closed and reopened.
